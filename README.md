# steal-the-car
---
## 게임소개
자동차를 훔치고 도망치는 게임입니다. 클로드를 이용해 만들었습니다. AI로 날먹한 게임이다 보니 그냥 즐겨주세요. 예상 못할 일이 일어날 겁니다.
## 사용법 
### 사람(걸어다닐때)
간단해요. `W`로 앞으로, `S`로 뒤로, `A`로 왼쪽으로.  `D`로 오른쪽으로, `Shift`로 달리기. `마우스`로 시점 이동입니다. `E`로 자동차에 탑승해요.
### 자동차
비슷합니다. `W`로 앞으로, `S`로 뒤로, `A`로 핸들 왼쪽으로 꺾고, `D`로 핸들 오른쪽으로 돌려요. `Space`는 브레이크입니다. 차가 느리거나 멈췄을 때 `E`로 내려요.
## 지원 기기
*키보드와 마우스가 있는 모든 기기에서 지원됩니다.* 터치 지원은 안됩니다.
